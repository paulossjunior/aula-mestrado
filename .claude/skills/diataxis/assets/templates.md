# Esqueletos

Adapte livremente — o esqueleto serve para manter a disciplina do modo, não para
engessar. Traduza os cabeçalhos para o idioma do projeto.

---

## Tutorial

```markdown
# Primeiros passos com <produto>

Ao final deste tutorial você terá <resultado concreto e visível>.
Leva cerca de <N> minutos.

## O que você precisa
- <pré-requisito 1, com versão exata>
- <pré-requisito 2>

## 1. <Primeira ação>
<comando ou passo>

Você deve ver:
<saída esperada>

## 2. <Segunda ação>
...

## Pronto
Você construiu <resultado>. 

Próximos passos:
- Para resolver tarefas específicas, veja os [guias](...).
- Para entender por que <produto> funciona assim, veja [Sobre ...](...).
```

---

## Guia prático

```markdown
# Como <objetivo do usuário>

<Uma frase: quando você precisa disso.>

Pré-requisitos: <o que já deve estar pronto>.

## Passos
1. <ação>
2. <ação>
3. <ação>

## Variações
- Se <condição>, então <ajuste>.
- Em <ambiente alternativo>, use <variante>.

## Se der errado
| Sintoma | Causa provável | Solução |
| ------- | -------------- | ------- |
|         |                |         |

Detalhes de todos os parâmetros: [referência](...).
```

## Referência

```markdown
# Referência de <componente>

## <item / comando / endpoint>

<Uma frase descritiva do que faz.>

**Sintaxe/Assinatura:** `...`

| Parâmetro | Tipo | Padrão | Descrição |
| --------- | ---- | ------ | --------- |
|           |      |        |           |

**Retorno:** <tipo e significado>

**Erros:** <condições de erro e códigos>

**Exemplo**
```
<exemplo mínimo, sem narrativa>
```
```
